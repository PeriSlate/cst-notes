# Security policy

## Reporting a vulnerability

Do not report vulnerabilities through public issues if they could expose user data or provide an exploit path. Contact the maintainer privately through the contact method listed in the repository profile.

## Sensitive information

Never include patient information, case notes, surgeon names, hospital information, vault paths, API keys, credentials, or unredacted diagnostic exports in a report.

## Scope

CST Notes is intended to operate locally within an Obsidian vault. Reports involving access outside the vault, unexpected network traffic, data loss, or exposure of user content are high priority.
