# Contributing to CST Notes

CST Notes is proprietary software. Bug reports and feature suggestions are welcome through this repository's Issues page; this is not an open-source code contribution program. The LICENSE governs use and distribution.

## Report a problem

Include the plugin version, Obsidian version, operating system, steps to reproduce, expected result, and actual result. Use an empty test vault or synthetic examples where possible. Mention whether Obsidian Sync is involved.

Never attach a real vault or unredacted case notes, surgeon details, hospital details, patient information, credentials, or diagnostic exports. Redact screenshots and review any copied diagnostics before sharing.

For security vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.

## Suggest a feature

Describe the workflow problem and desired outcome. Avoid including clinical or identifying data.
